## Week 1 — HTML, CSS & JavaScript Fundamentals

**Project:** Lumina — Responsive Landing Page + Weather App

- Semantic HTML & CSS with Flexbox/Grid
- Responsive design (Plain CSS + Bootstrap versions)
- Weather API integration using Open-Meteo
- JavaScript: DOM manipulation, events, async/await, Fetch API

---

## Week 2 — React + Node.js Full-Stack Development

### Momentumate — Task & Course Progress Tracker
- JWT authentication with bcrypt
- Full CRUD operations
- Progress tracking with Recharts
- File uploads with Multer
- MongoDB with Mongoose

### Pageturn — Role-Based Book E-Commerce
- Role-based access (Admin/User)
- Admin: Product CRUD, dashboard stats
- User: Browse, favorites, cart, checkout
- Redux Toolkit for state management
- Open Library Covers API integration

**Tech Stack:** React, Node.js, Express, MongoDB, JWT, Redux Toolkit

## Week 3 — MailMind: AI-Powered Email Template Generator 🤖

**AI-driven personalized email template generator**

### Features
- AI-powered email generation
- Personalized templates based on user prompts
- Real-time preview
- Modern, responsive UI
- Copy & save templates

### Tech Stack
**Frontend:** React + Vite, Redux Toolkit, Axios  
**Backend:** Node.js + Express

### Project Structure
```
Week3/

│   └── server.js

    ├── src/
    │   ├── App.jsx
    │   ├── features/emailSlice.js
    │   └── app/store.js
    └── package.json
```

### How to Run
```bash
# Backend
cd Week3/AI-Email-Generator
npm install
npm start

# Frontend
cd Week3/AI-Email-Generator-Frontend
npm install
npm run dev
```
